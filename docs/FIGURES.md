
# Figures

`figures/Fig01` through `figures/Fig08` are the manuscript figures. Figure 3 shows four qualitative cases from real held-out Test windows.

Figures 4-8 are regenerated from `results/figure_data/` with:

```bash
python scripts/reproduce_figures.py --fig all
```

Figures 1 and 2 are schematic summary figures. Their underlying workflow and data-role definitions are documented in `results/figure_data/`. Figure 8 is also regenerated by the figure script.

Figure 3 provenance is documented in `FIGURE3_PROVENANCE.md`. The official nuScenes semantic-prior map is used only for visualization and is not provided to predictors, post-processing methods, the candidate-selection procedure, or quantitative evaluation. Raw map assets and the trajectory NPZ are not included.

Display mapping: `raw` -> Raw; `sg_w5_p2` -> Fixed SG(5,2); `qreg_l1` -> QReg-L1; `qreg_l01` -> QReg-L0.1; `PositionalTransformer` -> Pos-Transformer.
