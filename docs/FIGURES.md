
# Figures

`figures/Fig01` through `figures/Fig08` are the final manuscript-facing exports. Figure 3 is uniquely the real held-out Test qualitative trajectory figure with four real-BEV panels. The earlier predictor-stratified artwork is not retained as formal Figure 3.

Figures 4-8 are regenerated from `results/figure_data/` with:

```bash
python scripts/reproduce_figures.py --fig all
```

Figures 1 and 2 are author-created schematic/summary artwork retained as final exports; their underlying workflow and log-effect sources are documented in `results/figure_data/`. Figure 8 is also regenerated by the public script.

Figure 3 provenance is documented in `FIGURE3_PROVENANCE.md`. The official nuScenes semantic-prior map provides visualization context only. It is not provided to predictors, post-processing methods, candidate selection, or quantitative evaluation. Raw map assets and the trajectory NPZ are not included.

Display mapping: `raw` -> Raw; `sg_w5_p2` -> Fixed SG(5,2); `qreg_l1` -> QReg-L1; `qreg_l01` -> QReg-L0.1; `PositionalTransformer` -> Pos-Transformer.
