# Fig.1 icon sources

**Historical journal-specific artwork only.** The current Fig.1 is a different workflow and does not use these five RQ icons. This record and the licensed source files are retained for provenance; see `docs/FIGURES.md` for the current figure mapping.

Tabler Icons official repository, immutable upstream commit `74929e50416e2b7c0abb8368cdc74bdcb2560ab6`. All five are Outline icons. Original SVG files are retained byte-for-byte. MIT license and copyright notice: `icon_sources/tabler/LICENSE`.

| RQ | Tabler icon name | Official page | SVG file | Path modified |
|---|---|---|---|---|
| RQ1 | `chart-line` | [chart-line](https://tabler.io/icons/icon/chart-line) | `icon_sources/tabler/chart-line.svg` | No |
| RQ2 | `chart-scatter` | [chart-scatter](https://tabler.io/icons/icon/chart-scatter) | `icon_sources/tabler/chart-scatter.svg` | No |
| RQ3a | `layout-grid` | [layout-grid](https://tabler.io/icons/icon/layout-grid) | `icon_sources/tabler/layout-grid.svg` | No |
| RQ3b | `adjustments-horizontal` | [adjustments-horizontal](https://tabler.io/icons/icon/adjustments-horizontal) | `icon_sources/tabler/adjustments-horizontal.svg` | No |
| RQ4 | `timeline` | [timeline](https://tabler.io/icons/icon/timeline) | `icon_sources/tabler/timeline.svg` | No |

Each icon retains the official 24 × 24 viewBox, stroke-width 2, fill none, stroke currentColor, linecaps, linejoins, and all original path/shape attributes. Only the enclosing viewport dimensions, placement and inherited colour are customized. No redrawing, boolean merging or combined paths.

Publication placement: 7 mm square viewport, centered on the existing RQ x coordinate and existing glyph center y=403; inherited colour #667483. RQ labels, all text, protocol nodes, data, canvas and other figures are unchanged.

The glyphs identify analysis topics, not experimental results. The existing Fig1 caption remains unchanged.

The draw.io source embeds the same original icon SVG shapes as images. The publication SVG remains editable path geometry. PNG is rendered from that publication SVG; no draw.io CLI rendering is claimed.
