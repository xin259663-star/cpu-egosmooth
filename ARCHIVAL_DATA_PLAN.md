
# Archival Data Plan

GitHub should remain lightweight. If authors later decide to release complete checkpoints, 50-run predictions, large parquet files, or large NPZ artifacts, use a separately reviewed Zenodo, OSF, or institutional repository deposit. Before deposit, verify nuScenes-derived-data redistribution terms, remove private paths and environment identifiers, provide checksums and a manifest, and document the linkage key. Do not configure an archive or mint a DOI without explicit author approval. After an archival DOI exists, update README and `CITATION.cff` in a separate reviewed commit.
